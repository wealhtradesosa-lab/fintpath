# FINPATH

**Tu camino a la libertad financiera** 🚀

Plataforma fintech premium para personas y familias que quieren entender, organizar y proyectar su libertad financiera.

## Features

- 📊 **Dashboard** — Patrimonio neto, cash flow, salud financiera
- 📈 **Inversiones** — Portfolio con sub-unidades, NOI, ROI, Cap Rate
- 💹 **Trading** — Portafolio de acciones y crypto con P/L
- 💳 **Gastos** — Gastos familiares categorizados
- 📋 **Deudas** — Con vinculación a activos
- 🖥️ **Simulador** — 4 escenarios (Actual, Conservador, Optimista, Crisis)
- 🏦 **Patrimonio** — Análisis de diversificación y distribución
- ⏰ **Pensiones** — Tradicional + Estrategia BTC (DCA, regla 4%)
- 🧠 **Coach IA** — 5 asesores legendarios (Kiyosaki, Robbins, Dalio, Buffett, Munger)
- ⭐ **Planes** — Free / Pro $29/año / Family $49/año

## Tech Stack

- **Frontend:** React 18 + Vite
- **Charts:** Recharts
- **Storage:** localStorage (demo) → Supabase (production)
- **Deploy:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

Push to `main` → Vercel auto-deploys.
